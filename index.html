Which characters survive, and where

      

      
      
    

    

      
RFC 3986 splits characters into unreserved ones, which never need escaping, and reserved ones, which carry meaning in some part of a URL and must be escaped everywhere else. A green tick means the character can appear literally in that component.

Where your data goes

    

  

    
Nowhere. Every conversion on this page is plain JavaScript running inside your tab. The page loads no scripts, styles, fonts or images from anywhere else, and makes no network requests while you use it.

    
Only two things are stored, both in this browser's local storage and only on this device: your language and theme choice, and nothing else. Clearing site data removes them.

    
“Copy workspace link” puts your current input into the link's fragment. Fragments are never sent to a server, but anyone you send the link to can read it — so treat a shared link like the data it carries.
